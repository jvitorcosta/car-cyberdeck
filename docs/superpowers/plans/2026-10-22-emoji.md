# Emoji Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Colour emoji (Twemoji, 16 px, ~600 most used) in every name and lyric line drawn through `glyphrun`/`textdraw`, instead of being dropped.

**Architecture:** A generator packs palette-indexed 16x16 emoji into `data/emoji16.bin` (media partition on the S3, embedded on the companion). A pure reader (`ui/emojifont`) looks keys up by binary search; `glyphrun::decode` learns 4-byte UTF-8, sequence collapsing and flags, and emits `Kind::Emoji` items; `textdraw` draws them as runs of `fillRect`.

**Tech Stack:** C++17 (Arduino-ESP32 2.0.17, TFT_eSPI), Unity host tests via `tools/run_tests.ps1`, Python 3 + Pillow for the generator.

**Spec:** `docs/superpowers/specs/2026-10-22-emoji-design.md`

## Global Constraints

- Glyph record: 160 B = 16 x u16 LE RGB565 palette (index 0 = transparent) + 128 B pixels, row-major, high nibble = left pixel.
- Blob: `"EMJ1"`, `u16 count`, `count` x `u32 key` ascending, then glyphs; glyph i at `6 + 4*count + 160*i`.
- Flag key: `0x110000 + a*26 + b`, a/b = regional indicator - U+1F1E6 (0..25).
- Emoji item width 16; drawn at `CJK_DY`; no shadow; index 0 skipped.
- 0 bytes of resident RAM for emoji; target ~100 KB of flash.
- Text without emoji must decode, fit and wrap exactly as before.
- Conventional commits `type(scope): subject` + the Co-Authored-By line.

## Review Focus

- A name that is only emoji ("🔥🔥🔥") with `fit`: must truncate with "..." on width, not overrun `cap`.
- A 4-byte sequence cut at the end of the string (Spotify names cut at 96 B): dropped, no read past the NUL.
- ZWJ followed by ASCII ("a‍b"): the ASCII letter is kept (only a non-ASCII codepoint is swallowed).
- `decode` with no emoji callback (old callers, ledpanel builds of util/): emoji still dropped, no crash.
- A corrupt or missing `emoji16.bin` (empty media partition): font stays empty, emoji dropped, text still drawn.
