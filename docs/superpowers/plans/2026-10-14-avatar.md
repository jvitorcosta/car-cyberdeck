# Deck Avatar (Step 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Now and then, the S3 deck's avatar slides into the album-art box with an expression, says a canned line in the dialogue box (her mouth flaps while it types), then the deck goes back to normal. Her portraits come from the owner's git-ignored images.

**Architecture:**
- **Converter:** a PC tool, `tools/gen_avatar.py` (ffmpeg), turns `avatar-photos/` and its `avatar.json` into `data/avatar.bin`. Only the S3 build embeds that file. A pre-build script writes an empty file when there is none.
- **Pure modules, host-tested with Unity:**
  - `util/avatarbin` parses the file;
  - `util/avatarlines` decides when she speaks and what she says;
  - `util/avatarscene` is the timeline (slide, typing, mouth frame, hold).
- **On the deck:** `ui/avatar` draws her frames row by row from flash and runs the scene. `ui/screen_now` gets the name tag. `main.cpp` calls the boot and track hooks, ticks the scene, and holds back the album art while she's on screen.

**Tech Stack:**
- PlatformIO espressif32@6.9.0, arduino-esp32 2.0.17, C++17, TFT_eSPI 2.5.43.
- Unity host tests via `tools/run_tests.ps1`.
- Python 3.12 with ffmpeg/ffprobe for the converter; `unittest` for its tests.

**Spec:** `docs/superpowers/specs/2026-10-14-avatar-design.md`

## Global Constraints

- **Branch:** do this work on a new branch, `feat/avatar`, created from the current `feat/better-link` HEAD (which holds the spec commits). Don't use `main`.
- **Builds:** S3 only. The CYD builds (`cyd`, `cyd_companion`) must not embed `data/avatar.bin`, and they must still build. CI checks the CYD's flash against **97 %**.
- **Committed vs. local:** the character art, `avatar-photos/` and `data/avatar.bin` are never committed. They're git-ignored. Tests use made-up names and lines only.
- **Feature off:** without a valid `data/avatar.bin`, the deck behaves exactly as today.
- **File format:**
  - Header: `"AVT1"`, u8 mood count `n` (1–8), u8 0, name (12 bytes, NUL-padded ASCII), then `n` × (u8 mood id, u8 frame count 1–8).
  - Then every frame as 92×92 RGB565, **high byte first**, mood by mood.
  - Mood ids: `0` smug, `1` talk, `2` happy.
- **Track remarks:** at most one per **5 minutes**, and a **1-in-3** chance per eligible track change. The boot greeting always plays, with a boot line.
- **Scene timing:**
  - slide-in: **240 ms** in 6 steps;
  - typing: **25 ms** per character;
  - mouth frame changes every **100 ms**;
  - hold: **3000 ms** after the line is complete.
- **Interruptions:** she never shows on a status screen. A track change or a status screen cancels her scene.
- **Commits:** conventional style, `type(scope): subject`, ending with the `Co-Authored-By` line.

## Review Focus

1. **A broken or partial `data/avatar.bin`:** for example, a gen_avatar run cut off half way, or a hand-edited header. Expected: the feature turns off with a log line, and the deck runs normally. Never a crash or garbage pixels. (Task 1: size-mismatch and bad-count tests.)
2. **A remark during the very first song after boot:** the boot greeting just played. Expected: no second scene within 5 minutes. (Task 2: `test_track_too_soon_after_boot_greeting`.)
3. **Title, artist or Pokémon name empty, very long, or accented:** for example, a local file with no artist, or a 95-byte Japanese title. Expected: a sensible fallback word, truncation that never cuts a UTF-8 character, and no overflow. (Task 2: fill tests.)
4. **A song change while she's talking:** expected: the new song's deck shows at once, and she doesn't stay half-drawn over the new art. (Task 6: cancel before `drawNow`.)
5. **Album art that arrives during her scene:** expected: the art doesn't overwrite her; it shows as soon as she leaves. If no art arrived at all, the box goes back to the plain sky. (Task 6: deferral; Task 7 device check.)

`src/util/avatarbin.h`:

```cpp
#pragma once
#include <cstddef>
#include <cstdint>
// data/avatar.bin (tools/gen_avatar.py): the deck avatar's portraits. PURE, host-tested.
// "AVT1", u8 mood count n (1..8), u8 0, name (12 bytes, NUL-padded ASCII), n x (u8 mood id,
// u8 frame count 1..8), then every frame as 92x92 RGB565 high byte first, mood by mood.
// Spec: docs/superpowers/specs/2026-10-14-avatar-design.md
namespace avatarbin {
constexpr int SIDE = 92;
constexpr size_t FRAME_BYTES = (size_t)SIDE * SIDE * 2;
constexpr int MAX_MOODS = 8, MAX_FRAMES = 8, NAME_LEN = 12;
enum Mood : uint8_t { Smug = 0, Talk = 1, Happy = 2 };
struct Info {
    int moods;                        // 0 = no avatar (feature off)
    char name[NAME_LEN + 1];
    uint8_t id[MAX_MOODS], frames[MAX_MOODS];
    uint32_t first[MAX_MOODS];        // byte offset of each entry's frame 0
};
// Parses blob into out. False (out.moods = 0) for a missing, empty or malformed file; `why`
// (may be nullptr) gets a short reason for the log, "" on success.
bool parse(const uint8_t* blob, size_t len, Info& out, const char** why);
// Entry index for mood id; 0 (the first mood) when the file has no such mood.
int find(const Info& in, uint8_t id);
// Byte offset of frame f of entry e; e and f are clamped into range.
uint32_t frameOffset(const Info& in, int e, int f);
}
```

`src/util/avatarbin.cpp`:

```cpp
#include "avatarbin.h"
#include <cstring>

namespace avatarbin {
static bool fail(Info& out, const char** why, const char* reason) {
    out.moods = 0;
    out.name[0] = '\0';
    if (why) *why = reason;
    return false;
}

bool parse(const uint8_t* b, size_t len, Info& out, const char** why) {
    if (!b || len < 18) return fail(out, why, "no file");
    if (memcmp(b, "AVT1", 4) != 0) return fail(out, why, "bad magic");
    const int n = b[4];
    if (n == 0) return fail(out, why, "no moods");
    if (n > MAX_MOODS) return fail(out, why, "too many moods");
    const size_t head = 18 + 2 * (size_t)n;
    if (len < head) return fail(out, why, "short header");
    size_t off = head;
    for (int e = 0; e < n; ++e) {
        const uint8_t k = b[18 + 2 * e + 1];
        if (k == 0 || k > MAX_FRAMES) return fail(out, why, "bad frame count");
        out.id[e] = b[18 + 2 * e];
        out.frames[e] = k;
        out.first[e] = (uint32_t)off;
        off += k * FRAME_BYTES;
    }
    if (len != off) return fail(out, why, "size mismatch");
    memcpy(out.name, b + 6, NAME_LEN);
    out.name[NAME_LEN] = '\0';
    out.moods = n;
    if (why) *why = "";
    return true;
}

int find(const Info& in, uint8_t id) {
    for (int e = 0; e < in.moods; ++e)
        if (in.id[e] == id) return e;
    return 0;
}

uint32_t frameOffset(const Info& in, int e, int f) {
    if (e < 0 || e >= in.moods) e = 0;
    if (f >= in.frames[e]) f = in.frames[e] - 1;
    if (f < 0) f = 0;
    return in.first[e] + (uint32_t)f * (uint32_t)FRAME_BYTES;
}
}
```

```cpp
#pragma once
#include <cstddef>
#include <cstdint>
// When the deck avatar speaks and what she says: canned lines on boot and, now and then, on a
// new track. PURE, host-tested. Spec: docs/superpowers/specs/2026-10-14-avatar-design.md
namespace avatarlines {
constexpr size_t TEXT_CAP = 160;
constexpr uint32_t GAP_MS = 5UL * 60 * 1000;   // at most one track remark per 5 min
constexpr uint32_t ODDS = 3;                    // then 1 in ODDS track changes
enum class Event : uint8_t { Boot, Track };
struct In {
    Event event;
    bool spokeBefore;       // she has had a scene since boot
    uint32_t sinceLastMs;   // since her last scene started (ignored when !spokeBefore)
    uint32_t rnd;           // a random draw (esp_random on the deck)
    const char* title;      // may be nullptr / ""
    const char* artist;
    const char* poke;       // the walking Pokemon, as stored
};
struct Out {
    uint8_t mood;           // avatarbin::Mood
    char text[TEXT_CAP];
};
// True, with out filled, when she should speak now.
bool pick(const In& in, Out& out);
// Copies tmpl into out (n bytes incl. NUL), replacing {T} with the title, {A} with the artist
// and {P} with the Pokemon in capitals. Empty values: "this song", "this artist", "POKéMON".
// Never cuts a UTF-8 character; other braces are copied as they are.
void fill(const char* tmpl, const char* title, const char* artist, const char* poke, char* out,
          size_t n);
struct Line {
    uint8_t mood;
    const char* text;
};
constexpr int BOOT_N = 3, TRACK_N = 12;
extern const Line BOOT[BOOT_N];
extern const Line TRACK[TRACK_N];
}
```

```cpp
const Line TRACK[TRACK_N] = {
    {Smug, "Darling, {A} again?"},
    {Talk, "Ooh, {T}! Turn it up~"},
    {Happy, "I like this one, darling!"},
    {Talk, "A wild {P}! Bet it can't keep up with us."},
    {Smug, "{P} is cute. Not as cute as me."},
    {Talk, "Sing along, darling. I won't laugh. Much."},
    {Happy, "This one's for the road~"},
    {Talk, "{A}? You have good taste, darling."},
    {Smug, "Eyes on the road, darling."},
    {Talk, "{P} wants to ride with us."},
    {Happy, "Faster, darling! ...Kidding. Drive safe."},
    {Talk, "Just us, the road and {T}."},
};

// Appends len bytes of s at out[o], whole UTF-8 characters only; false once one doesn't fit.
static bool append(char* out, size_t n, size_t& o, const char* s, size_t len, bool upper) {
    for (size_t i = 0; i < len;) {
        const unsigned char c = (unsigned char)s[i];
        size_t cl = c < 0x80 ? 1 : (c >> 5) == 6 ? 2 : (c >> 4) == 14 ? 3 : (c >> 3) == 30 ? 4 : 1;
        if (i + cl > len) cl = len - i;
        if (o + cl + 1 > n) return false;
        for (size_t k = 0; k < cl; ++k) {
            const char ch = s[i + k];
            out[o++] = (upper && ch >= 'a' && ch <= 'z') ? (char)(ch - 32) : ch;
        }
        i += cl;
    }
    return true;
}

void fill(const char* tmpl, const char* title, const char* artist, const char* poke, char* out,
          size_t n) {
    if (!out || n == 0) return;
    const char* T = title && *title ? title : "this song";
    const char* A = artist && *artist ? artist : "this artist";
    const char* P = poke && *poke ? poke : "POK\xC3\xA9MON";
    size_t o = 0;
    for (const char* p = tmpl ? tmpl : ""; *p;) {
        if (p[0] == '{' && (p[1] == 'T' || p[1] == 'A' || p[1] == 'P') && p[2] == '}') {
            const char* v = p[1] == 'T' ? T : p[1] == 'A' ? A : P;
            if (!append(out, n, o, v, strlen(v), p[1] == 'P')) break;
            p += 3;
            continue;
        }
        const char* brace = strchr(p + 1, '{');             // literal run up to the next brace
        const size_t lit = brace ? (size_t)(brace - p) : strlen(p);
        if (!append(out, n, o, p, lit, false)) break;
        p += lit;
    }
    out[o] = '\0';
}

bool pick(const In& in, Out& out) {
    const Line* l;
    if (in.event == Event::Boot) {
        l = &BOOT[in.rnd % BOOT_N];
    } else {
        if (in.spokeBefore && in.sinceLastMs < GAP_MS) return false;
        if (in.rnd % ODDS != 0) return false;
        l = &TRACK[(in.rnd / ODDS) % TRACK_N];
    }
    out.mood = l->mood;
    fill(l->text, in.title, in.artist, in.poke, out.text, sizeof out.text);
    return true;
}
}
```

```cpp
#pragma once
#include <cstddef>
#include <cstdint>
// The deck avatar's scene timeline: she slides into the art box, types her line while her mouth
// flaps, holds it, then leaves. PURE, host-tested.
// Spec: docs/superpowers/specs/2026-10-14-avatar-design.md ("Her scene").
namespace avatarscene {
constexpr int SIDE = 92;
constexpr uint32_t SLIDE_MS = 240;   // STEPS steps of 40 ms
constexpr int STEPS = 6;
constexpr uint32_t CHAR_MS = 25;     // ~40 characters per second
constexpr uint32_t MOUTH_MS = 100;   // the mouth opens / closes at most this often
constexpr uint32_t HOLD_MS = 3000;   // the whole line stays up this long
enum class Phase : uint8_t { Slide, Type, Hold, Done };
struct State {
    Phase phase;
    int shown;      // portrait columns visible at the left of the art box (0..SIDE)
    size_t bytes;   // UTF-8 prefix of the line typed so far (whole characters)
    int frame;      // the mood's frame to show (0 = rest, mouth closed)
};
// ms: since the scene started; line: her text (nullptr = ""); frames: the mood's frame count.
State at(uint32_t ms, const char* line, int frames);
}
```

`src/util/avatarscene.cpp`:

```cpp
#include "avatarscene.h"
#include <cstring>

namespace avatarscene {
// Byte length of the first n characters of s; *total = its character count.
static size_t prefix(const char* s, size_t n, size_t* total) {
    size_t chars = 0, cut = 0, i = 0;
    for (; s[i]; ++i) {
        if (((unsigned char)s[i] & 0xC0) == 0x80) continue;   // UTF-8 continuation byte
        if (chars == n) cut = i;
        ++chars;
    }
    if (chars <= n) cut = i;
    *total = chars;
    return cut;
}

// Letters, digits and non-ASCII characters move the mouth; spaces and punctuation don't.
static bool voiced(unsigned char c) {
    return c >= 0x80 || (c >= '0' && c <= '9') || ((c | 0x20) >= 'a' && (c | 0x20) <= 'z');
}

State at(uint32_t ms, const char* line, int frames) {
    const char* s = line ? line : "";
    State st{Phase::Slide, SIDE, 0, 0};
    if (ms < SLIDE_MS) {
        st.shown = SIDE * (int)(ms * STEPS / SLIDE_MS + 1) / STEPS;
        return st;
    }
    const uint32_t t = ms - SLIDE_MS;
    size_t total = 0;
    const size_t typed = t / CHAR_MS;
    st.bytes = prefix(s, typed, &total);
    if (typed < total) {
        st.phase = Phase::Type;
        if (frames > 1 && st.bytes > 0 && voiced((unsigned char)s[st.bytes - 1]) &&
            (t / MOUTH_MS) % 2 == 0)
            st.frame = 1 + (int)((t / (2 * MOUTH_MS)) % (uint32_t)(frames - 1));
        return st;
    }
    st.bytes = strlen(s);
    st.phase = t < total * CHAR_MS + HOLD_MS ? Phase::Hold : Phase::Done;
    return st;
}
}
```

`tools/gen_avatar.py`:

```python
"""Build data/avatar.bin: the deck avatar's portraits from the owner's images
(docs/superpowers/specs/2026-10-14-avatar-design.md).
Run: python tools/gen_avatar.py [folder]      (default: avatar-photos/, which holds avatar.json)
The images and data/avatar.bin are git-ignored: the character art isn't ours to publish.
Needs ffmpeg and ffprobe.

avatar.json:
  {"name": "ZERO TWO",
   "moods": {"smug":  {"file": "a.png", "crop": [size, x, y], "colors": 0, "boost": false},
             "talk":  {"frames": ["rest.png", "open.png"]},
             "happy": {"file": "b.png"}}}
An image that is already 92x92 is used as is (crop, colors and boost are ignored for it).
Others are cropped square, optionally boosted, line-thickened (erosion), area-scaled to 92x92
and, with "colors": N, given their own N-colour palette without dithering.

Format: "AVT1", u8 mood count, u8 0, name (12 bytes, NUL-padded ASCII), count x (u8 mood id,
u8 frame count), then every frame as 92x92 RGB565, high byte first, mood by mood.
Also writes avatar-preview.png (all frames at 4x) into the folder.
"""
import json
import os
import struct
import subprocess
import sys

ROOT = os.path.join(os.path.dirname(os.path.abspath(__file__)), "..")
OUT = os.path.join(ROOT, "data", "avatar.bin")
SIDE = 92
FRAME = SIDE * SIDE * 2
MOODS = {"smug": 0, "talk": 1, "happy": 2}
MAX_FRAMES = 8
NAME_LEN = 12
BOOST = "eq=saturation=1.35:contrast=1.12"   # for washed-out anime frames


class ManifestError(Exception):
    pass


def validate(manifest, folder, size_of):
    """Checks avatar.json. Returns (name, [(mood id, [(path, entry), ...]), ...]) in file order.
    size_of(path) -> (width, height)."""
    name = manifest.get("name", "")
    if not isinstance(name, str) or not name or len(name) > NAME_LEN or not name.isascii():
        raise ManifestError(f"name must be 1-{NAME_LEN} ASCII characters")
    moods = manifest.get("moods") or {}
    if not moods:
        raise ManifestError("no moods")
    out = []
    for mood, entry in moods.items():
        if mood not in MOODS:
            raise ManifestError(f"unknown mood '{mood}' (use {', '.join(MOODS)})")
        if ("file" in entry) == ("frames" in entry):
            raise ManifestError(f"{mood}: give exactly one of 'file' and 'frames'")
        files = [entry["file"]] if "file" in entry else list(entry["frames"])
        if not 1 <= len(files) <= MAX_FRAMES:
            raise ManifestError(f"{mood}: 1-{MAX_FRAMES} frames")
        frames = []
        for f in files:
            path = os.path.join(folder, f)
            if not os.path.isfile(path):
                raise ManifestError(f"{mood}: missing file {f}")
            w, h = size_of(path)
            if (w, h) != (SIDE, SIDE):
                crop = entry.get("crop")
                if not crop or len(crop) != 3:
                    raise ManifestError(f"{mood}: {f} is {w}x{h}, so it needs \"crop\": [size, x, y]")
                c, x, y = crop
                if c <= 0 or x < 0 or y < 0 or x + c > w or y + c > h:
                    raise ManifestError(f"{mood}: crop {crop} is outside {f} ({w}x{h})")
            frames.append((path, entry))
        out.append((MOODS[mood], frames))
    return name, out


def rgb565be(rgb):
    """RGB24 bytes -> RGB565, high byte first (the order pushImage sends)."""
    out = bytearray()
    for i in range(0, len(rgb), 3):
        r, g, b = rgb[i], rgb[i + 1], rgb[i + 2]
        out += struct.pack(">H", ((r >> 3) << 11) | ((g >> 2) << 5) | (b >> 3))
    return bytes(out)


def pack(name, moods):
    """moods: [(mood id, [frame bytes, FRAME each])] -> the avatar.bin bytes."""
    head = b"AVT1" + bytes([len(moods), 0]) + name.encode("ascii").ljust(NAME_LEN, b"\0")
    for mood_id, frames in moods:
        head += bytes([mood_id, len(frames)])
    return head + b"".join(f for _, frames in moods for f in frames)


def size_of(path):
    r = subprocess.run(["ffprobe", "-v", "error", "-show_entries", "stream=width,height",
                        "-of", "csv=p=0", path], check=True, capture_output=True, text=True)
    w, h = r.stdout.strip().splitlines()[0].split(",")[:2]
    return int(w), int(h)


def rgb24(path, entry):
    """One 92x92 frame as RGB24 bytes."""
    if size_of(path) == (SIDE, SIDE):
        graph = "null"
    else:
        c, x, y = entry["crop"]
        chain = [f"crop={c}:{c}:{x}:{y}"]
        if entry.get("boost"):
            chain.append(BOOST)
        chain += ["erosion", f"scale={SIDE}:{SIDE}:flags=area"]   # thicken lines, then shrink
        graph = ",".join(chain)
        colors = int(entry.get("colors", 0))
        if colors:
            graph += (f",split[a][b];[a]palettegen=max_colors={colors}:reserve_transparent=0"
                      f":stats_mode=full[p];[b][p]paletteuse=dither=none")
    r = subprocess.run(["ffmpeg", "-v", "error", "-i", path, "-filter_complex", graph,
                        "-frames:v", "1", "-f", "rawvideo", "-pix_fmt", "rgb24", "-"],
                       check=True, capture_output=True)
    if len(r.stdout) != SIDE * SIDE * 3:
        raise ManifestError(f"{path}: ffmpeg returned {len(r.stdout)} bytes")
    return r.stdout


def preview(frames, path):
    """All frames side by side at 4x."""
    strip = bytearray()
    for y in range(SIDE):
        for f in frames:
            strip += f[y * SIDE * 3:(y + 1) * SIDE * 3]
    subprocess.run(["ffmpeg", "-v", "error", "-y", "-f", "rawvideo", "-pix_fmt", "rgb24",
                    "-s", f"{SIDE * len(frames)}x{SIDE}", "-i", "-",
                    "-vf", "scale=iw*4:ih*4:flags=neighbor", path], input=bytes(strip), check=True)


def main():
    folder = sys.argv[1] if len(sys.argv) > 1 else os.path.join(ROOT, "avatar-photos")
    try:
        with open(os.path.join(folder, "avatar.json"), encoding="utf-8") as f:
            manifest = json.load(f)
        name, moods = validate(manifest, folder, size_of)
        shown, packed = [], []
        for mood_id, frames in moods:
            rgb = [rgb24(p, e) for p, e in frames]
            shown += rgb
            packed.append((mood_id, [rgb565be(x) for x in rgb]))
    except (OSError, ValueError, ManifestError, subprocess.CalledProcessError) as e:
        sys.exit(f"gen_avatar: {e}")
    blob = pack(name, packed)
    os.makedirs(os.path.dirname(OUT), exist_ok=True)
    with open(OUT, "wb") as f:
        f.write(blob)
    preview(shown, os.path.join(folder, "avatar-preview.png"))
    print(f"gen_avatar: {name}, {len(packed)} moods, {len(shown)} frames, {len(blob)} bytes -> {OUT}")


if __name__ == "__main__":
    main()
```

```cpp
#include "avatar.h"
#include <Arduino.h>
#include <cstring>
#include "screen_now.h"
#include "../util/avatarbin.h"
#include "../util/avatarlines.h"
#include "../util/avatarscene.h"

#ifdef BOARD_S3   // only the S3 embeds data/avatar.bin (platformio.ini)
extern const uint8_t _binary_data_avatar_bin_start[] asm("_binary_data_avatar_bin_start");
extern const uint8_t _binary_data_avatar_bin_end[] asm("_binary_data_avatar_bin_end");
#endif

namespace ui {
static avatarbin::Info s_info{};
static const uint8_t* s_blob = nullptr;
static bool s_active = false;
static uint32_t s_t0 = 0;
static int s_entry = 0;
static char s_text[avatarlines::TEXT_CAP];
static int s_shown = -1, s_frame = -1;    // what is on screen now (-1: nothing yet)
static size_t s_bytes = (size_t)-1;       // typed prefix on screen ((size_t)-1: tag not drawn)

bool avatarBegin() {
    s_info.moods = 0;
#ifdef BOARD_S3
    const char* why = "";
    s_blob = _binary_data_avatar_bin_start;
    const size_t len = (size_t)(_binary_data_avatar_bin_end - _binary_data_avatar_bin_start);
    if (avatarbin::parse(s_blob, len, s_info, &why)) {
        Serial.printf("[avatar] %s: %d moods\n", s_info.name, s_info.moods);
        return true;
    }
    Serial.printf("[avatar] off: %s\n", why);
#endif
    return false;
}

bool avatarOn() { return s_info.moods > 0; }
bool avatarActive() { return s_active; }

void avatarStart(uint8_t mood, const char* text, uint32_t nowMs) {
    if (!avatarOn()) return;
    s_entry = avatarbin::find(s_info, mood);
    strlcpy(s_text, text ? text : "", sizeof s_text);
    s_t0 = nowMs;
    s_active = true;
    s_shown = s_frame = -1;
    s_bytes = (size_t)-1;
}

void avatarCancel() { s_active = false; }

// Frame f of entry e with its right `shown` columns at the left of the art box. Rows go through
// a RAM buffer: the embedded file need not be 2-byte aligned, and only visible columns are sent.
static void drawFrame(TFT_eSPI& t, int e, int f, int shown) {
    constexpr int N = avatarbin::SIDE;
    if (shown <= 0) return;
    if (shown > N) shown = N;
    const uint8_t* px = s_blob + avatarbin::frameOffset(s_info, e, f);
    const int skip = N - shown;               // columns still outside the box, on the left
    static uint16_t row[N];
    for (int y = 0; y < N; ++y) {
        memcpy(row, px + ((size_t)y * N + skip) * 2, (size_t)shown * 2);
        t.pushImage(ART_X, ART_Y + y, shown, 1, row);   // bytes as stored: RGB565 high byte first
    }
}

AvatarTick avatarTick(TFT_eSPI& t, uint32_t nowMs) {
    if (!s_active) return AvatarTick::Idle;
    const avatarscene::State st = avatarscene::at(nowMs - s_t0, s_text, s_info.frames[s_entry]);
    if (st.phase == avatarscene::Phase::Done) {
        s_active = false;
        return AvatarTick::Ended;
    }
    if (st.shown != s_shown || st.frame != s_frame) {
        drawFrame(t, s_entry, st.frame, st.shown);
        s_shown = st.shown;
        s_frame = st.frame;
    }
    if (st.phase != avatarscene::Phase::Slide && st.bytes != s_bytes) {
        if (s_bytes == (size_t)-1) drawNameTag(t, s_info.name);   // once, when typing starts
        char typed[avatarlines::TEXT_CAP];
        memcpy(typed, s_text, st.bytes);
        typed[st.bytes] = '\0';
        drawLyricArea(t, typed, false);
        s_bytes = st.bytes;
    }
    return AvatarTick::Running;
}
}
```

```cpp
#pragma once
#include <cstdint>
// The companion avatar singing along with synced lyrics: when her mouth moves for the line on
// screen. PURE, host-tested. Spec: docs/superpowers/specs/2026-10-14-avatar-design.md (Revision).
namespace avatarsing {
constexpr uint32_t FLAP_MS = 150;        // mouth open / closed every 150 ms
constexpr uint32_t LONE_LINE_MS = 4000;  // a line with no next line is sung this long
// True while the line that started at lineStartMs is sung at song position posMs: the first
// 3/4 of the time to the next line (nextStartMs; 0 = none, then LONE_LINE_MS).
bool singing(uint32_t posMs, uint32_t lineStartMs, uint32_t nextStartMs);
// The frame for a mood with `frames` frames: open (1) and rest (0) alternating every FLAP_MS
// while singing; 0 otherwise.
int frame(uint32_t posMs, uint32_t lineStartMs, uint32_t nextStartMs, int frames);
}
```

`src/util/avatarsing.cpp`:

```cpp
#include "avatarsing.h"

namespace avatarsing {
bool singing(uint32_t posMs, uint32_t lineStartMs, uint32_t nextStartMs) {
    if (posMs < lineStartMs) return false;
    const uint32_t len = nextStartMs > lineStartMs ? (nextStartMs - lineStartMs) * 3 / 4 : LONE_LINE_MS;
    return posMs - lineStartMs < len;
}

int frame(uint32_t posMs, uint32_t lineStartMs, uint32_t nextStartMs, int frames) {
    if (frames < 2 || !singing(posMs, lineStartMs, nextStartMs)) return 0;
    return ((posMs - lineStartMs) / FLAP_MS) % 2 == 0 ? 1 : 0;
}
}
```

```cpp
#include "avatarview.h"
#include <Arduino.h>
#include <cstring>
#include <esp_system.h>
#include "../ui/theme.h"
#include "../util/avatarbin.h"
#include "../util/avatarlines.h"
#include "../util/avatarscene.h"
#include "../util/avatarsing.h"

extern const uint8_t _binary_data_avatar_bin_start[] asm("_binary_data_avatar_bin_start");
extern const uint8_t _binary_data_avatar_bin_end[] asm("_binary_data_avatar_bin_end");

namespace avatarview {
static constexpr uint16_t TAG_PINK = 0xF497;   // #F090B8
static avatarbin::Info s_info{};
static int s_entry = -1, s_frame = -1;           // on screen (-1: repaint)
static bool s_tag = false;
static bool s_talking = false;                    // her own line is up
static uint32_t s_t0 = 0;
static int s_lineEntry = 0;
static char s_text[avatarlines::TEXT_CAP], s_typed[avatarlines::TEXT_CAP];

bool begin() {
    const char* why = "";
    const size_t len = (size_t)(_binary_data_avatar_bin_end - _binary_data_avatar_bin_start);
    if (avatarbin::parse(_binary_data_avatar_bin_start, len, s_info, &why)) {
        Serial.printf("[avatar] %s: %d moods\n", s_info.name, s_info.moods);
        return true;
    }
    Serial.printf("[avatar] off: %s\n", why);
    return false;
}

bool on() { return s_info.moods > 0; }
void invalidate() { s_entry = s_frame = -1; s_tag = false; }

// Whole frame, row by row through a RAM buffer (the embedded file need not be 2-byte aligned).
static void show(TFT_eSPI& t, int e, int f) {
    constexpr int N = avatarbin::SIDE;
    if (e == s_entry && f == s_frame) return;
    const uint8_t* px = _binary_data_avatar_bin_start + avatarbin::frameOffset(s_info, e, f);
    static uint16_t row[N];
    for (int y = 0; y < N; ++y) {
        memcpy(row, px + (size_t)y * N * 2, N * 2);
        t.pushImage(X, Y + y, N, 1, row);       // bytes as stored: RGB565 high byte first
    }
    s_entry = e;
    s_frame = f;
    if (!s_tag) {                                // the name tag, centred under her
        const int w = (int)strlen(s_info.name) * 6 + 6;
        const int x = X + (N - w) / 2;
        t.fillRect(x, Y + N + 4, w, 9, TAG_PINK);
        t.setTextDatum(TL_DATUM);
        t.setTextColor(TFT_WHITE, TAG_PINK);
        t.drawString(s_info.name, x + 3, Y + N + 5, 1);
        s_tag = true;
    }
}

static void speak(avatarlines::Event ev, const decklink::View& v, uint32_t now) {
    static bool spoke = false;
    static uint32_t lastAt = 0;
    static avatarlines::Out out;
    const avatarlines::In in{ev, spoke, now - lastAt, esp_random(), v.deck.track, v.deck.artist, ""};
    if (!avatarlines::pick(in, out)) return;
    spoke = true;
    lastAt = now;
    s_lineEntry = avatarbin::find(s_info, out.mood);
    strlcpy(s_text, out.text, sizeof s_text);
    s_t0 = now;
    s_talking = true;
    Serial.printf("[avatar] says: %s\n", out.text);
}

const char* update(TFT_eSPI& t, const decklink::View& v, uint32_t now) {
    if (!on()) return nullptr;
    static bool greeted = false;
    static uint32_t gen = 0;
    if (v.polledAtMs && v.deckOk) {              // events come from the new deck's feed
        if (!greeted) {
            greeted = true;
            gen = v.deck.trackGen;
            speak(avatarlines::Event::Boot, v, now);
        } else if (v.deck.trackGen != gen) {
            gen = v.deck.trackGen;
            speak(avatarlines::Event::Track, v, now);
        }
    }
    if (s_talking) {                             // her line: typing + hold (no slide: she is on)
        const avatarscene::State st = avatarscene::at(now - s_t0 + avatarscene::SLIDE_MS, s_text,
                                                      s_info.frames[s_lineEntry]);
        if (st.phase != avatarscene::Phase::Done) {
            show(t, s_lineEntry, st.frame);
            memcpy(s_typed, s_text, st.bytes);
            s_typed[st.bytes] = '\0';
            return s_typed;
        }
        s_talking = false;
    }
    const stateparse::Deck& d = v.deck;
    const int talk = avatarbin::find(s_info, avatarbin::Talk);
    const bool synced = strcmp(d.lyricKind, "synced") == 0;
    if (v.polledAtMs && d.playing && synced && d.line[0] && s_info.id[talk] == avatarbin::Talk) {
        const uint32_t pos = d.progressMs + (now - v.polledAtMs);
        uint32_t start = d.lineStartMs, next = d.nextStartMs;
        if (next && pos >= next) {               // the next line is already on screen
            start = next;
            next = 0;
        }
        show(t, talk, avatarsing::frame(pos, start, next, s_info.frames[talk]));
    } else {
        show(t, avatarbin::find(s_info, avatarbin::Smug), 0);
    }
    return nullptr;
}
}
```

```cpp
// Big line in the column [x0, W): font 2 at 2x over up to two rows when the whole line fits,
// else at 1x over two rows (glyphrun::wrapTwo, "..." if even that is too long). Centred.
static void bigLine(TFT_eSPI& t, const char* text, int x0, int cy) {
    constexpr size_t MAX = 160;
    static glyphrun::Item items[MAX + 3];   // + room for a "..." on the second row
    const size_t n = glyphrun::decode(text, items, MAX, ui::asciiWidth2, ui::wideWidth, &t);
    const int colW = W - x0 - 24, cx = x0 + (W - x0) / 2;
    const uint16_t fg = theme::pal().topText, sh = TFT_BLACK;
    const int dot = ui::asciiWidth2('.', &t);
    int scale = 2;
    glyphrun::Wrap w = glyphrun::wrapTwo(items, n, colW / 2, 3 * dot);   // items keep 1x widths
    if (w.bEllipsis) {
        scale = 1;
        w = glyphrun::wrapTwo(items, n, colW, 3 * dot);
    }
    const int dy = scale == 2 ? 18 : 9;
    auto run = [&](const glyphrun::Item* it, size_t k, int y) {
        if (scale == 2) ui::drawRunScaled(t, it, k, cx, y, fg, sh, MC_DATUM, 2);
        else ui::drawRun(t, it, k, cx, y, fg, sh, MC_DATUM);
    };
    if (w.bStart >= w.bEnd) {
        run(items, w.aEnd, cy);
        return;
    }
    run(items, w.aEnd, cy - dy);
    size_t bn = w.bEnd - w.bStart;
    if (w.bEllipsis) {   // items past bEnd are not drawn, so "..." can overwrite them
        for (int k = 0; k < 3; ++k)
            items[w.bEnd + k] = {glyphrun::Kind::Ascii, '.', txt::Mark::None, '.', (uint8_t)dot};
        bn += 3;
    }
    run(items + w.bStart, bn, cy + dy);
}
```
